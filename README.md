# My File Server (خادم الملفات الشخصي)

تطبيق ويب خفيف وسريع مبني بلغة Python لإدارة ومشاركة الملفات على الشبكة المحلية بسهولة، مع دعم كامل للتشغيل عبر حاويات Docker.

## المميزات
* **سهولة التصفح والمشاركة:** الوصول إلى الملفات ورفعها وتحميلها عبر المتصفح من أي جهاز متصل بالشبكة.
* **خفيف وسريع:** مبني بهيكلية بسيطة تضمن سرعة الاستجابة واستهلاكًا منخفضًا لموارد الجهاز.
* **دعم Docker:** جاهز للنشر والتشغيل المباشر في أي بيئة باستخدام ملف `Dockerfile` المرفق.

## طريقة التشغيل

### 1. التشغيل المباشر باستخدام Python
تأكد من تثبيت Python على جهازك، ثم نفذ الأوامر التالية في مجلد المشروع:
```bash
pip install -r requirements.txt
python app.py
```

### 2. التشغيل باستخدام Docker
لبناء وتشغيل الحاوية مباشرة:
```bash
docker build -t my-file-server .
docker run -d -p 8000:8000 my-file-server
```
*(ملاحظة: تأكد من مطابقة رقم المنفذ `8000` مع المنفذ المحدد داخل ملف `app.py`)*
